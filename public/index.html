Règles
  • Trouvez le mot secret. Chaque proposition reçoit une température : la similarité cosinus entre les deux mots dans le modèle word2vec, multipliée par 100.
  • Si le mot fait partie des 1000 mots les plus proches du mot secret, une progression en ‰ s'affiche : 999 ‰ pour le plus proche, 1 ‰ pour le 999e. Le mot secret vaut 1000 ‰.
  • 🧊 température négative · 🥶 hors du top 1000 · 😎 top 1000 · 🥵 ≥ 900 ‰ · 🔥 ≥ 990 ‰ · 😱 999 ‰ · 🥳 trouvé.
  • Seules les formes de base sont connues : infinitif pour les verbes, masculin singulier pour les noms et adjectifs (chanter, pas chantons). Les accents oubliés sont rattrapés quand il n'y a pas d'ambiguïté.
  • Parties illimitées : une nouvelle partie tire un nouveau mot au hasard.
